# 왕국과 반란

PC 브라우저에서 방을 만들고 6자리 코드로 참가하는 실시간 비공개 카드 게임입니다. 서로 다른 와이파이에서도 **인터넷에 배포한 동일한 주소**로 접속하면 함께 플레이합니다. 대화는 디스코드를 사용합니다.

## 혼자서 AI와 플레이

방을 만든 뒤 **AI 추가**를 두 번 눌러 사람 1명 + AI 2명으로 시작할 수 있습니다. 실제 PPO 셀프플레이로 학습한 `models/policy.json`을 서버에서 실행합니다. 외부 AI API는 사용하지 않습니다. AI도 자기 손패와 공개된 정보만 봅니다.

추가 학습은 다음 명령으로 실행합니다. 모델 저장 후 서버를 재시작하면 적용됩니다.

```bash
npm run ai:train -- --resume models/policy.json --episodes 3000
npm run ai:evaluate -- --games 300
```

학습 구조·평가·배포 방법은 **[ai/README.md](ai/README.md)**에 있습니다. 모델은 초기 학습 단계이며 사람 수준의 실력을 보장하지 않습니다.

## 로컬 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 **http://localhost:3000**을 엽니다. 한 PC에서 테스트할 때는 서로 다른 브라우저나 독립 시크릿 세션을 사용하세요. 같은 브라우저의 같은 사이트는 하나의 플레이어로 복귀하도록 설계되어 있습니다.

```bash
npm test
```

## 무료 인터넷 배포: Render

Render의 무료 **Web Service**를 사용합니다. WebSocket을 지원하므로 별도의 소켓 서버는 필요 없습니다. 정적 사이트 서비스로는 게임 서버를 실행할 수 없습니다.

1. 이 폴더의 코드를 자신의 GitHub 저장소에 올립니다. `node_modules`, `.data`, `.env`는 올리지 않습니다.
   - **`models/policy.json`을 반드시 포함**해야 AI 참가자가 동작합니다. `ai/` 폴더도 포함하세요. `.checkpoint.json`은 배포에 필요 없습니다.
2. [Render](https://dashboard.render.com/)에 로그인합니다.
3. **New → Blueprint**에서 저장소를 연결하면 `render.yaml` 설정을 사용할 수 있습니다.
4. 직접 **New → Web Service**로 만드는 경우 아래 설정을 사용합니다.

   | 항목 | 값 |
   | --- | --- |
   | Runtime | Node |
   | Build Command | `npm ci` |
   | Start Command | `npm start` |
   | Instance Type | **Free** |
   | Health Check | `/health` |

5. 배포가 끝나면 Render가 발급한 `https://서비스이름.onrender.com` 주소를 공유합니다.
6. 한 명이 방을 만들고 방 코드나 화면의 **초대 링크 복사**로 친구들을 초대합니다.

배포하려면 본인의 GitHub·Render 계정에서 저장소 연결이 필요합니다. 이 프로젝트에는 배포 설정이 포함되어 있으며, 아직 공개 서버 주소가 발급된 상태는 아닙니다.

### 무료 호스팅과 재접속

- 브라우저 새로고침·일시적인 네트워크 끊김: 같은 브라우저의 저장된 비밀 복귀 토큰으로 직업·손패·차례를 복구합니다. 접속 끊김은 자동 패스하지 않습니다.
- 동일 플레이어가 다른 탭에서 복귀하면 가장 최근 연결이 활성화됩니다.
- 게임 중에도 상단 **방 나가기**로 홈에 돌아갈 수 있습니다. 진행 중에는 연결만 해제하고 직업·손패·자리를 보존합니다. 본인 차례는 자동으로 넘기지 않고 복귀를 기다립니다. 홈의 **원래 방으로 돌아가기** 버튼으로 재입장합니다. 대기실에서는 참가자 명단에서 제거하고 방장 권한을 위임합니다.
- 로컬 서버는 `.data/rooms.json`에 게임을 저장하므로 정상적인 서버 재시작에도 복구합니다. `DATA_DIR` 환경변수로 저장 위치를 지정할 수 있습니다.
- **Render 무료 서버의 파일 저장소는 일시적**입니다. 서버 재배포·재시작·휴면 시 기존 방 데이터가 사라질 수 있습니다. 이 경우 새 방을 만들어야 합니다. 무료 서버는 접속이 없는 상태가 15분 이어지면 휴면하며 첫 접속 시 약 1분이 걸릴 수 있습니다.
- 서버 재시작을 넘어서 영구 복구가 필요하면 외부 영구 데이터베이스 연결을 추가해야 합니다.

공식 안내: [무료 서비스](https://render.com/docs/free), [WebSocket](https://render.com/docs/websocket).

## 구현한 규칙

### 진영과 승리

- 최소 3인. 3인은 왕·시민·반란군 각 1명. 4인은 중립 1명 추가.
- 5인 이상은 네 진영을 1명씩 기본 배치하고 방장이 추가 인원의 진영을 설정합니다. 왕은 항상 1명입니다.
- 시작 시 무작위 진영 배정. 왕 공개, 본인 진영만 확인. 반란군끼리는 서로 확인합니다.
- 게임 기간은 **3인 10일·4인 9일·5인 7일·6인 이상 6일**입니다. 일반 반란은 3인 **1일**, 4인 **2일**, 5인 이상 **3일** 성공하면 즉시 반란군 승리. 마지막 저녁까지 두 반란의 승리 목표를 막으면 왕·시민 승리.
- 마지막 날은 밤 없이 종료합니다. 방장이 대기실에서 원하는 중립 직업을 선택하면 중립에게 무작위로 배정하며 같은 직업은 중복되지 않습니다. 주교는 최대 1명이고 3인에는 중립 직업을 넣을 수 없습니다. 선택한 직업보다 중립 인원이 많으면 나머지는 일반 중립입니다.
- 주교는 **종교반란 4인 1일·5인 2일·6인 이상 3일 성공**으로 혼자 승리합니다. 일반 중립은 철혈의 검으로 승리할 수 있습니다.
- 철혈의 검을 보유하면 해당 진영 즉시 승리. 왕 또는 시민이면 왕·시민 공동 승리. **화염대검 1장 + 북부의 검 1장**을 모두 소모해 제작하며, 랜덤으로는 나오지 않습니다.

### 아침

시작 손패 **12장**. 매일 아침 시작 시 손패가 **6장 이하인 플레이어에게 5장 추가 지급**합니다(왕 포함, 하루 한 번). 첫날은 이미 12장이므로 추가 보급이 없습니다. 이후 왕이 아침 행동을 선택하고 재분배합니다.

- 밤의 반란력을 전원에게 공개. 0점이면 중재 불가.
- **중재:** 왕 선포 → 시민·중립 지원 확정(0장 가능) → 왕 제출 → 합계 비교. **반란군은 선포·지원·0장 제출 모두 불가**하며 기다리지 않습니다. 중재력이 반란력 이상이면 성공. 지원은 왕의 손패를 거치지 않고 일회용은 소모, 영구 전쟁병기는 유지합니다. 왕을 제외한 1장 이상 지원 인원수를 표시합니다.
- 중재 실패 또는 중재 미선택 시 반란 성공 1일. 판정 후 반란점수·설치 폭탄 초기화. 인원별 반란 목표에 도달하면 나머지 행동 없이 즉시 종료. 폭탄이 설치된 반란을 막지 못하면 왕·시민의 손패를 전부 버립니다. 설치 여부는 판정 전까지 공개하지 않습니다.
- **사형 투표:** **3인과 첫날 아침에도 가능**합니다. 왕이 선포하면 왕을 포함한 전원이 왕 이외의 플레이어에게 한 표씩 투표합니다. 최다 득표자를 사형하며 동률이면 최다 득표자 중 무작위 한 명을 고릅니다. **교단·전도·영구 카드를 포함한 모든 카드 몰수**, 탈락하지 않고 플레이를 계속합니다. 표는 마감 전 본인의 선택만 확인하고 마감 후 득표 합계와 결과를 공개합니다.
- **원정:** 전원이 하급·상급 투표, 과반 상급이면 상급, 동률은 하급. 왕 필참.
  - 하급: 나머지 자유 참가. **10점 이상** 성공: 전원 4장 / **20점 이상** 대성공: 전원 9장. 실패 패널티 없음.
  - 상급: 왕이 3인에서는 1명, 4인에서는 2명, 5인 이상에서는 3명 강제 지명(거절 불가). **전체 명단은 왕만 확인하고 각 당사자는 자기 지명 여부만 확인합니다. 다른 지명자·비지명자에게 명단을 보내지 않고 공개 기록에도 이름을 남기지 않습니다.** 왕과 지명된 사람만 제출. **30점 이상** 성공: 반란군 제외 전원 15장 / **50점 이상** 대성공: 반란군 제외 전원 25장. 실패: 반란군 제외 전원 손패 몰수.
  - 원정은 왕 포함, 1장 이상 낸 인원수만 표시합니다. 0장 제출은 수에 포함하지 않고 지명자의 이름을 카운트와 함께 보내지 않습니다.
  - 참가 여부와 관계없이 보상·패널티 대상이면 적용. 모든 진영은 공격 카드 사용 가능. 왕·시민은 보병 +1·장교 +3, 반란군은 반란 -2·선동 -6, 중립은 둘 다 가능. 왕·시민은 반란·선동 불가, 반란군은 보병·장교 불가.
- 아침 시작에 23장 초과 손패는 무작위로 **22장**까지 축소. 정확히 23장은 유지. 이번 아침 원정으로 받은 보상은 즉시 잘리지 않고 다음 아침에 제한을 적용합니다.
- 이후 각자 비공개 재분배 수락/거절: 수락하면 손패 전부 버리고 새로 **12장**, 거절하면 기존 손패 유지. **거절 시 손패가 8장 미만이면 부족한 장수만큼 무작위 카드를 추가해 8장으로 채웁니다.** 왕도 선택하며, 아침 시작의 6장 이하 +5장 보급과는 별도 규칙입니다.

### 낮

왕 이후 무작위 고정 순서로 세 바퀴. 행동과 카드 변화는 비공개이며, 현재 차례만 공개합니다. 패스 버튼은 없습니다.

1. **거래 / 채집(자원 6장) / 랜덤 카드 4장**
   - 거래 거절 시 신청자 차례 종료.
   - 거래 수락 시 양쪽이 비공개로 줄 카드를 선택·확정한 뒤 동시에 교환. 0장 허용. 상대 카드·수량은 교환 전까지 숨김.
2. **제작 / 사냥**
   - 제작은 원하는 만큼 반복·연속 가능, 완료 버튼으로 종료. 재료가 없는 경우에도 제작을 선택하고 완료 가능.
   - 사냥은 한 번. 공격력이 있는 카드 사용(보병·장교 제외). 공격력 **10 이상**이면 **7장**, 실패 보상 없음. 0장 사냥도 실패로 처리.
3. **전체 교체 / 5장 받기·일부 교체 / 타인 손패 전체 보기 / 타인 카드 2장 가져오기**
   - 전체 교체는 기존 장수만큼 새로 생성.
   - 5장 받기: 기존 손패 0~5장을 선택해 버리고 새 카드 5장을 받음. 0장 선택이면 5장 추가, 3장 선택이면 교체 3장+추가 2장, 5장 선택이면 교체만 5장.
   - 전체 보기는 한 사람의 확인 당시 손패를 본인에게만 표시. 카드 종류만 제공하며 상대 카드 ID는 제공하지 않습니다.
   - 가져오기는 한 사람에게서 무작위 **2장**을 실제 이전합니다. 부족하면 가진 만큼, 영구 카드도 이전 가능. 피해자에게 **카드를 빼앗겼다는 개인 알림·개수·전용 효과음·확인 전까지 유지되는 배너**를 표시합니다. 제3자에게는 알리지 않습니다.

### 저녁과 밤

- **세금징수:** 왕 제외 전원이 자신이 선택한 3장을 왕에게 납부. 부족하면 전부, 0장이면 0장 납부.
- **지명수배:** 왕 이외 1명 검사. **반란카드가 있을 때만** 반란·선동·병기·폭탄을 전부 버립니다. 자원·공격 카드·영구 카드·특수 검·전쟁병기는 남습니다. 선동만 있으면 몰수하지 않습니다. 왕은 반란·선동 존재 여부를 알고 전원은 처분 결과만 확인합니다.
- **시민지원:** 왕 제외 전원에게 랜덤 6장. 개인 수령 기록·새 카드 강조·즉시 효과를 표시합니다. 손패 23장을 넘겨도 즉시 버리지 않습니다.
- **밤:** 반란군이 반란력이 있는 카드를 원하는 만큼 제출. 0장 허용. 일회용은 소모, 영구 전쟁병기는 유지. 총점만 다음 아침 공개. 폭탄은 +5 반란력이며 판정 후 설치 여부 공개, 방어 실패 시 왕·시민만 손패 몰수.

일반 사용 카드는 성공·실패 관계없이 소모됩니다. 화염대검·북부의 검은 일회용입니다. 영구 카드는 각 행동당 카드별 한 번 사용하고 손패에 남으며, 재분배·몰수·제작 재료 사용 시에는 소모됩니다. 주교에게는 공통 제작과 주교 전용 제작을 제공합니다.

### 주교 · 종교반란

- 종교반란 성공 트랙은 기존 반란 트랙 위에 표시됩니다. 교단영향력은 주교 본인에게만 보이며 종교반란이 발생한 아침에는 종교반란력을 전원에게 공개합니다.
- 누구끼리의 **거래 또는 카드 뺏기**든 전도카드를 받은 사람이 주교가 아니라면 받은 전도카드 수만큼 일반 카드를 무작위 교단카드로 바꿉니다. 교단·전도카드는 변환 대상이 아닙니다. 일반 카드가 부족하면 나머지 수만큼 교단카드를 추가 지급합니다. 주교가 받으면 발동하지 않습니다.
- 주교 이외의 교단·전도카드는 일반 버림 효과에서 보호됩니다. 중재 사용·거래·카드 뺏기는 가능하고 세금은 카드 이전으로 처리합니다. **사형·종교개혁·종교반란 실패**는 보호 카드도 정리합니다. 주교 자신의 카드는 보호되지 않습니다.
- 재분배 수락 시 보호 카드를 남기고 새 카드 12장을 받습니다. 전체 교체는 보호 카드 이외의 카드만 같은 장수로 교체하고, 일부 교체에는 보호 카드를 선택할 수 없습니다. 폭탄·상급 원정 실패도 보호 카드는 유지합니다.
- 매일 아침 주교 이외의 플레이어는 가진 전도카드 수만큼 교단카드를 받은 뒤 손패 제한을 적용합니다. 손패가 23장을 넘으면 일반 카드를 무작위로 먼저 버리고, 부족한 경우에만 교단·전도카드를 버려 22장으로 줄입니다.
- 일반 반란 중재에서 누구든 교단(3점)·전도(7점)를 사용하면 그 중재력만큼 주교가 교단영향력을 얻습니다. 반란군은 일반 반란 중재에 참여할 수 없습니다.
- **밤 순서:** 모든 반란군의 행동이 끝난 뒤 주교가 원하는 행동을 여러 번 하고, 완료를 누르면 다음 아침으로 넘어갑니다.
  - **종교전도:** 교단 5장 소모 → 타인 손패에서 무작위 1장을 가져옴 → 그 사람에게 전도 1장 지급. 상대 손패가 비어 있으면 가져오는 카드 없이 전도만 지급합니다.
  - **종교반란:** 교단 12장 소모 → 다음 아침 종교반란 예약. 한 밤에 1번만 가능하며 다음 밤 다시 가능합니다. 밤 행동 종료 시의 교단영향력이 다음 아침 반란력이 됩니다.
  - **종교개혁:** 전도 5장 소모 → 자신 이외 모든 플레이어의 교단·전도카드를 버림 → 버린 **교단카드 수 × 2**만큼 영향력 증가.
  - **교단회수:** 전도 2장 소모 → 원하는 다른 플레이어 한 명의 교단카드를 **전부 자신의 손패로 이전**. 전도·일반 카드는 그대로 남고 영향력은 증가하지 않습니다. 비용이 있으면 반복 가능합니다.
- **종교반란 중재:** 반란군을 포함한 다른 플레이어도 지원할 수 있으나 교단·전도카드는 사용할 수 없습니다. 중재력이 종교반란력 이상이면 방어 성공입니다.
- 두 반란이 동시에 발생하면 왕은 하나만 중재하며 다른 반란은 자동 성공합니다. 두 진영이 동시에 목표에 도달하면 **왕이 중재하지 않은 쪽**이 승리합니다. 왕이 두 반란 모두 중재하지 않았다면 두 쪽 모두 조건을 충족하므로 공동 승리합니다.
- 종교반란이 끝나면 성공·실패와 관계없이 교단영향력은 0이 됩니다. 종교반란 실패 시 주교 이외의 모든 교단·전도카드가 버려집니다.

## 구조

### 화면 효과와 효과음

- 아침 반란점수를 큰 배너로 표시하고, 판정 후에는 방어 성공/실패 및 점수 비교를 그날 동안 유지합니다.
- 중재 결과·원정·정책은 공개 연출. 사냥·제작·거래·보급·납부·정보 확인은 서버에서 받은 본인 기록에만 연출을 적용합니다.
- 효과음은 브라우저 Web Audio로 생성합니다. 첫 클릭/키 입력 후 활성화되며 상단 버튼으로 끌 수 있습니다. 설정은 브라우저에 저장됩니다.
- 재접속 시 과거 효과를 한꺼번에 재생하지 않습니다. 동작 줄이기 환경 설정을 존중합니다.
- 효과 큐를 제거했습니다. 새 행동의 알림은 기존 알림을 즉시 교체하고 같은 업데이트의 결과는 묶어 표시합니다. 이전 예약 음을 중단하고 최신 효과음을 즉시 재생하며, 70ms 이내의 일반 효과는 합칩니다. 반란 결과·승패 효과는 우선합니다.
- 제작법 총 24종 중 화면·가이드에는 공통 9종과 본인 진영·직업 제작만 표시합니다(왕13/시민12/반란군13/일반 중립9/주교13종). 공개 `/api/rules`에는 공통만, 개인 상태에는 본인에게 허용된 제작법만 제공하며 레시피 ID로 권한도 검증합니다.
- 사람을 지정하는 행동은 작은 드롭다운 대신 큰 플레이어 카드·이름 강조로 선택합니다. 대상을 직접 선택하기 전에는 해당 행동 버튼이 비활성화됩니다.

- `lib/game.js`: 서버 전용 게임 규칙, 차례 검증, 개인별 비공개 상태 생성
- `server.js`: HTTP·Socket.IO, 방과 복귀 토큰, 상태 저장
- `public/`: PC 화면·카드 선택 UI·재연결
- `test/`: 승패 경계·비밀 정보·거래·재접속 검증
- `render.yaml`: Render 무료 Web Service 배포 설정
- `lib/ai-policy.js`, `lib/ai-runner.js`: 비공개 정보 보호·학습 모델 추론·AI 자동 차례
- `ai/`: 실제 엔진 셀프플레이·PPO 학습·독립 평가
- `models/policy.json`: 학습된 가중치·학습 횟수·평가 결과

클라이언트는 행동 요청만 보내고 서버가 손패·대상·차례·진영을 검증합니다. 타인 손패는 전체 보기 행동을 사용한 본인에게만 확인 당시 카드 종류를 제공합니다. 숨겨진 진영·타인 토큰·판정 전 폭탄·비공개 투표는 전송하지 않습니다. 현재 서버 한 인스턴스 기준입니다.
