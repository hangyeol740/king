## 최근 추가 대조에서 남은 구체적 결함
- PPO 종류/기본 매개변수는 독립된 construction-rules로 분리했다. 완전성 대조·장기 학습 실측은 남았다.
- 완성행동 joint likelihood ratio로 clip하고 동일행동 보상/시간할인/gradient 정규화를 보완했다. 장기 학습 실측은 남았다.
- 일부 조건 충돌은 여전히 전체 응답을 버린다. 독립 발언/행동 각각의 보존 및 재검토를 더 분리해야 한다.
- 즉시 동료 피해 검토의 전략 수치는 여전히 모델 평가이며 규칙상 손실과 분리된 구조가 충분하지 않다.
- 학습 평가의 긴 실행/중단복구·난이도효과 별도 평가·새 기준 실학습은 미실행.
- 통합 API 최신 코드 상황별20회 재검사 및 역할목표/누출/반복 대화 품질 합격은 미완료.

최근 통합 v3: 12상황×20회=240개 완료. 실행 경로 오류1(대장장이 입력/출력 카드수 혼동), 확정실패 사냥2는 품질문제로 표시. 제작조건 스키마·피드백 수정 후 해당상황 재검사 필요. 새학습은 아직 시작하지 않았다.

후속 v5/v6 각40회(사냥꾼20·대장장이20): 사냥꾼 확정실패 선택0. 대장장이 각1회는 올바르게 재작성된 미래제작 발언을 의미검토 모델이 다시 false로 판정해 중단. 원문·검토이유는 /tmp/opencode/runtime-targeted-v5.json 및 runtime-targeted-v6.json. 이 사례를 통과로 조작하지 않으며 규칙으로 증명 가능한 단일 제작문장의 직접 검증을 추가했다. 최신 재검사는 아직 필요하다.

추가 수정: 온라인 실시간 학습도 실제 행동 직전 자산 스냅샷으로 같은 reward-ledger 사용. 저장실패 결과 완료플래그는 성공후 기록. 스트리밍 파일복구·원문 채널별 아카이브·기권 종료후 복귀권한·모든실시간방 사람0명 검사 연결.
