# 이메일 인증 가입

서버 환경변수:
- `RESEND_API_KEY`: Resend API 키 (서버 전용)
- `RESEND_FROM`: Resend에서 인증한 도메인의 발신 주소, 예: `Coup <auth@example.com>`

가입: 이메일·아이디·비밀번호·재입력 → 6자리 번호 요청 → 이메일 번호 입력 → 가입.
번호는 10분 유효, 이메일별 1분 재요청 제한, 최대 5회 검증, 성공 후 폐기. 이메일 원문·번호·API 키를 로그에 출력하지 않습니다. 아이디 중복은 최종 계정 생성 시에도 차단합니다.

현재 게임 서버는 장기 실행 Node.js 구조이고 인증 대기 정보는 서버 메모리에 있습니다. 재시작 시 인증번호를 다시 요청해야 합니다. 아직 진행하지 않은 Vercel/Supabase 전환 시 인증 대기 정보·이메일별 제한을 Supabase의 서버전용 테이블/트랜잭션으로 옮겨야 합니다. 현재 파일만 Vercel 함수에 복사하면 다중 인스턴스에서 동작하지 않습니다.

실제 메일 발송은 Resend 키와 검증된 발신 도메인을 설정한 환경에서 별도 확인해야 합니다. 단위 테스트는 모의 Resend 응답을 사용합니다.
