# 통합 관찰·계획·행동 에이전트

## 배포 경로

게임 중 대화와 봇 차례는 `lib/cognitive-agent.js`를 공유합니다. 로비만 기존 `openai-chat.js`를 사용합니다. `lib/agent-mind.js`가 개인 기억과 계획을 관리하고, `lib/agent-client.js`가 서버 환경변수로 API를 호출합니다. 학습기 `ai/train-agent.js`도 같은 모듈을 그대로 사용합니다.

1. `view(room, bot.id)`와 접근 가능한 한 채널의 `chatView`로만 관찰을 구성합니다. 상대 진영/손패를 원본 방에서 꺼내지 않습니다. 원본 채팅의 sender는 본인 발언 표시 여부에만 사용하고 상대 ID는 전달하지 않습니다.
2. 공개 사건, 익명 주장, 본인의 직접 관찰을 구분해 근거 ID를 붙입니다. 상대 지원/참가 성향과 LLM 추정을 낮은 확신으로 기록합니다. 모델의 판단이 사실이라는 뜻은 아닙니다. 채널별 관찰60개, 추정6개, 이전 계획12개로 상한을 둡니다.
3. 진영 목표, 현재 목표, 상대에게 유도할 믿음, 실제 행동, 공개 약속, 수정 이유를 한 번에 선택합니다. 현재 합법 후보의 index만 허용합니다.
4. 질문/제안/수락/거절/역제안/응답/침묵을 선택합니다. 블러핑 모드에서만 공개 약속 후보와 실제 행동 후보의 차이를 허용합니다. 다른 모드의 구조화된 약속 위반은 거절합니다. 자연어 문장과 구조화된 약속의 의미까지 완벽히 검증하는 것은 아닙니다.
5. 필요하면 응답을 기다립니다(선택적4.5초). 다른 AI가 한 번 응답할 수도 있습니다. 새 공개 사건/채널 메시지가 들어오면 예산 내에서 실행 전에 다시 판단합니다. 변경 이유 없는 실행 후보 변경은 거절합니다.
6. 저장한 실제 후보를 봇 runner가 다시 합법성 검증 후 실행합니다. 계획에는 executed/revised/expired/invalidated/superseded와 결과를 남겨 다음 판단에 제공합니다.

## 비동기·비용·권한

- 봇별 API 동시 실행과 방별 runner 재진입을 막습니다. API 처리 중 상태/채널 권한/게임 인스턴스가 바뀌면 응답을 폐기합니다. API 타임아웃25초, 계획 만료90초입니다.
- 기본 방당 하루 자발 판단6회, 응답 판단24회. 봇의 신규 자발 판단은 하루2회(기존 실행 계획 재검토는 방 예산을 공유). 예산 소진/API 오류/불합법 계획은 기존 게임 정책의 합법 행동으로 진행하며 거짓 API 성공으로 기록하지 않습니다.
- 비밀 채널의 과거 계획/대화는 공개 채널 프롬프트에 넣지 않습니다. 내부 계획·진영 목표·추론·원본 발신자 ID는 클라이언트 view로 보내지 않습니다. 새 게임 시작 시 기억을 초기화합니다.
- JSON Schema에 합법 행동 인덱스·실제 근거ID·필수 필드를 넣고 응답 후 재검증합니다. 프롬프트 지침만으로 비밀 발언 유출/부정확한 자연어를 완전히 방지한다고 주장하지 않습니다.
- `/api/ai-chat/status`의 `engine: observe-plan-act`, `agentVersion: 1`, decisions/revisions/spoken/silent/discarded/invalid로 확인합니다. API 성공과 계획 검증 성공은 별도 지표입니다. revisions는 수정 이유가 포함된 판단 횟수이며 단계 변경도 포함합니다. 로비 API 통계는 이 통합 에이전트 지표에 합산되지 않습니다.

## 동일 에이전트 자연어 학습

```
node ai/train-agent.js --episodes 4 --eval-pairs 3 --calls-per-game 9 --seed 142028
```

실제 한국어 대화로 게임을 끝까지 진행합니다. 학습 대상은 전역 사회전략 선택 가중치이며 LLM 자체 파인튜닝은 아닙니다. 전체 게임 중 예산 안의 결정은 통합 에이전트, 나머지는 기존 게임 정책을 사용합니다. 기본적으로 최소 여러 날에 호출 예산을 분산합니다. 상대에게 신중/협상/보존 스타일을 부여하지만 상대 전략은 이번 파일럿에서 honest로 고정합니다. 다양한 블러핑 상대를 포함한 리그 학습은 아직 아닙니다.

최종 스키마 검증 후 실행 결과:

- 훈련4판 + 별도평가6판, 실제 BAZE gpt-6-luna API86회, 유효한 계획86회, API/계획 검증 오류0회.
- 발언68회, 침묵18회. 수정 이유 포함 판단37회(새 단계에 따른 계획 재검토 포함).
- 후보2/3승, 정직 비교2/3승. 표본이 매우 작고 이후 덱 추첨은 crypto 난수라 승률 개선 근거로 사용하지 않습니다.
- 새 상위 정책 가중치는 배포하지 않습니다. 배포하는 것은 통합 판단 구조이며, 기본 사회전략 선택은 수동 균등 탐색입니다. 기존 게임정책 모델 가중치도 보존합니다.
- 초기 기능 검증24호출, 근거ID 제약 도입 전 실험147호출은 디버깅 실행이었습니다. 최종 저장된 결과는 위86호출 실행입니다.

`models/agent-candidate.json`, `agent-evaluation.json`, `agent-traces.json`에 결과를 보관합니다. traces는 인공 게임 데이터이며 실제 사용자 대화나 API 키를 담지 않습니다. 관찰→발언→계획→실행/수정 상태를 기록합니다. 인간 같은 사회성, 장기 설득 효과, 기존 AI 대비 승률 개선은 아직 검증하지 않았습니다.
