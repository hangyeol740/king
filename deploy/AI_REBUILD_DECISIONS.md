# AI 재설계 확정 사항

## 추가 문답 1~84의 최종 결정 — 아래 기존 요약과 충돌하면 이 절 우선

### 판단·정보·협의
- 동료 피해는 원칙적으로 반란군방에서 먼저 협의. 반란군 총2명일 때 타인 발언자는 유일 동료로 추론 가능. 3명 이상은 자기소개를 묻고 주장으로 연결하며 서버의 숨겨진 작성자ID를 사용하지 않음. 자기소개 충돌시 연결 보류·재확인.
- 무응답이면 다른 합리적인 행동 선택. 긴급 승리 기회/패배 방지 등 구체적 팀 이득이 있으면 무응답 또는 거절에도 예외 검토. 처형에도 동일 기준. 당일 손패 조사만 요구하거나 처형만 무조건 막는 임시 제한은 확정안이 아님.
- 규칙으로 계산 가능한 소모/획득/이전과 모델의 불확실한 전략 이득을 분리하고 대안과 비교. 말로만 팀 이득 숫자를 적는 것은 검증이 아님.
- 매 대화마다 행동도 재검토. 병렬 결과 충돌은 영향받은 부분만 재판단하고 독립 결과는 보존. 관련된 새 메시지는 행동 실행 전에 검토하되 무관한 인사로 실행을 막지 않음.
- 발언과 행동의 대상·조건·사건·수치 전제를 연결해 각각 재검증. 오래된 손패는 조사 당시 사실/현재 추정으로 구분.
- 장기 기억은 원본 사건에 연결한 요약·검색. 요약과 원문 충돌시 원문 우선·의존 계획 재검토. 대체AI는 이전 사람이 본 대화에서 의사 추출·불확실성 유지.
- 다른 비밀채널 누출은 모델 지시·사후 평가만 적용. 전송 전 별도 누출 차단 모델은 추가하지 않음.

### 의사·표현
- 같은 기회·같은 조건의 여러 채널 지원 발언은 동일 의사에 출처들을 연결. 별도 지원이라고 말한 경우만 합산.
- '7점'/'딱7점'은 정확7점, '최소7점'은 하한. 대상·행동 기회·반란 종류·카드수·제작수량 등 발언 조건 저장. 조건 불충족은 이행 처리하지 않음.
- 해당 기회를 놓치면 미이행 결과로 종료. 시간으로 단순 만료시키거나 다음 날 다른 기회에 임의 적용하지 않음.
- 비밀방 거래는 확인된 대상 이름으로 연결하고 방ID를 1대1 매칭ID와 비교하지 않음.
- 말/결정 불일치시 구조화된 결정 의미로 대사 재작성. 관련 대사 확정 뒤 실행하고, 재작성은 행동을 임의 변경하지 않음.
- 잘못된 JSON/후보/필드는 오류 이유와 최신 입력으로 재판단. 고정 대사나 임의 행동으로 덮지 않음.

### 기권 최종 규칙
- 개인 기권은 자산·제출·대화 승계, 원래 사람−120점 기권패·복귀 불가. AI는 원래 역할 목표와 승리 자격 유지.
- 진영 기권 가결은 진영 사람들의 기권 및 AI 승계. 전체 과반수와 해당 진영 사람 과반수 모두 필요. 찬성자−120점, 반대자는 일반 패배 점수(왕−110/나머지−80). 반대자도 해당 게임 복귀 불가. 대체AI는 승리 가능.
- 자동 승리는 명시적 기권으로 사람이 남은 승리목표 진영이 하나로 줄었을 때 적용. 원래부터 사람 한 진영인 게임은 자동 승리하지 않음. 같은 진영 AI도 승리, 원래 기권자는 패배. 일반중립 각자 독립.
- 마지막 진영 기권 투표는 부결. 마지막 개인 기권은 허용하되 승자 없이 종료. 모든 실시간 방에서 미기권 사람이0명이면 종료; 학습 시뮬레이션은 예외. 일시 연결 끊김은 기권 아님.
- 대체AI가 반란 목표 달성 또는 왕국 마지막날 방어 시 원래 승리 규칙 적용. 사람이 기권했다고 AI의 승리까지 금지하지 않음.

### 학습·평가
- PPO 자체를 행동종류→대상→카드→수량 순차 구성 정책으로 재설계. LLM만 직접행동을 구성하고 PPO는 작은 후보만 고르는 방안은 선택하지 않음.
- 모든 합법 선택을 구성 가능하게 하되 전부 열거/저장하지 않음. 구성 규칙·당시 입력·전달한 비교 후보 전체·구성 행동·검증 결과를 보관.
- 전투는 실제 소모·획득·동료 피해·팀 영향 평가. 원정은 정책/투표/지명/참가/제출을 동일 사건에 연결하되 보상 중복 지급 금지. 모든 학습 방식에 같은 보상 규칙.
- 패배시 양의 보상 항목만 제거하고 음의 비용 및 최종 패배 학습 유지. 무승부 최종0점·중간 손익 유지. 평가 순위는 실제 승률, 무승부율 별도.
- 매 주기부터 역할×상대 조합별 최소500판, 승률5% 이상·기존 대비 최대3%p 하락. 최종 상대유형별1000판도 충족. 경계는 조합별 최대5000판, 다중조합·반복검사를 고려한 전체95% 기준. 끝까지 불확실하면 보류·기존 유지.
- 기본 모델 실력과6난이도 효과 평가는 분리. 상대풀 변경시 모든 후보 재평가. 탈락시 검증 최고 모델과 짝인 optimizer로 돌아가 재시도. 총 시도와 가중치 학습 계보 별도.
- 이전 가중치 의미별 이전하되 새 특징이 기존 행동에 주는 영향은0으로 시작. 새 요청 행동은 낮은 초기 확률·학습 가능.
- 실제 API는 상황별20회 원문·선택·실행·침묵·오류 대조. 목표 혼동/의도치 않은 말행동 불일치 재현시 관련 승격 보류.
- 사람 기록은 당시 개인 관점의 자기발언/타인익명발언/상황을 보존. 손익·대안 검증된 표본만 학습, 부족시 모방 학습 보류. 외부LLM 미세조정은 이번 범위 제외.

### 연결·운영·기록
- API 공통 공급자/키/주소/모델 설정. 요청60초 초과시 최신 상태로 재요청·중복실행 금지. 지속설정오류는 서버 재시작/복원 뒤 재판단.
- API 미설정시 AI게임 시작 차단. 로비 AI대화 비활성.
- 참가자에게 생각중/정상침묵/일시·설정오류 상태만 전용 알림. 상세 전략/오류는 서버 진단. 상태 알림은 AI 새 판단 trigger가 아님.
- 서버 canAct와 후보 불일치는 재구성 시도·진단 표시. 해결 안 되면 해당 필수 차례 대기, 임의 진행 금지.
- 원격 실패는 로컬 내구 대기열·제한된 메모리 묶음·점진간격 재시도. 로컬까지 실패해도 게임 계속·누락 범위 명시. 무기한 원문 보관·새 버전 저장공간으로 이전 자료와 분리.
- 재시작시 미완료 요청/실행예약 해제·사건ID로 중복 방지·최신 상태 재판단. 기억/약속은 유지.

위 결정은 구현 완료를 의미하지 않는다. 아래는 최초 문답 당시의 요약이며 이후 변경은 위 최종 결정을 따른다.

사용자 문답으로 확정. 전체 결정 후 구현하며 운영 오류 수정과 모델 승격을 분리한다.

- 기습 정보: 본인 차례와 전투 당사자만 상대 식별 정보를 받음.
- 개인 기권 추가, 진영 기권 별도 유지. 자산·제출·기억·채널을 AI가 승계. 사람 복귀 불가·기권패−120점, 대체 AI는 새 승리 자격을 가진 참가자로 진영을 유지. 왕국/반란/주교/상인/일반중립 개인별 승리 목표로 남은 진영 계산.
- 알려진 반란군 동료 피해는 구조화된 팀 손익·대안·근거가 있는 경우만 허용. 왕/시민은 서로 숨겨진 시민 진영을 모르며 반란군끼리만 동료를 앎.
- 자기 정체 주장/거짓말 허용. 어려움 이상 직업 특혜는 대화·행동 모두 사용 가능. 익명 발신자는 식별 금지.
- 채팅/행동 계산은 동시에 하되 공유 계획 버전으로 적용 전 검증. 발언과 행동은 단일 결정 의미를 사용. 필수 행동 판단이 끝나지 않으면 기다림. 지속 API 고장 시 해당 AI의 필수 차례만 대기·UI 상태 표시.
- 약속은 강제가 아닌 선호. 조건/상대/점수/기회 기록, 내부 이유를 남기고 공개 철회 없이 변경 가능. 현재 상태에서 불가능하면 재판단. 상대 미확정 거래는 공개 닉네임 질문. 허세 의도는 상황별 선택.
- 의미/목적 기반 반복 억제, 이유 있는 침묵 허용. 대체 고정 대사로 오류 위장 금지.
- 기습 시도 보상 제거, 구조화 결과 사건으로 개인·팀 손익 귀속. 패배 게임의 양의 중간 보상 취소하되 최종 패배 학습 유지.
- 사냥꾼8점 공통 규칙, 모든 직업 균형 연습, 신원조사 개인 매칭 정보, 개인별 대상 특징·허용 직업 지식 PPO 반영.
- 거절 시 추가 행동 포함 해당 차례 종료. 매우쉬움 steal만 금지, 낮 본인 행동 시작35% 건너뛰기 유지. 제작 재료 반환은 제작1회별 독립 판정.
- 1대1 수신은 차례 밖 개별 수락/거절. 사회 행동 일일 상한 대신 상태·목적 중복 기준.
- 평가 상대 바뀌면 전체 후보 재평가. 여러 검증 모델 균등 순환·실게임 난수 유지. 모든 주기 평가부터 역할별500판, 절대5%, 기존 대비 최대3%p 하락. 최종 후보별 상대 유형별1000판. 부족 표본은 미완료. 통과 후보 중 최고만 승격.
- 기존1020 가중치 의미별 이전 가능하나 기존 데이터/평가와 새 자료는 버전별 별도 저장. 모델·옵티마이저·후보·상대풀·정책 RNG·진행도 완전 재개. crypto 게임 난수는 정확 재개 불가능을 명시.
- 사람 모든 채널 원문은 분리된 학습 후보로 무기한 보관. 개인정보·권한 누출 금지, 버전·완전 행동·사전 상태·검증 결과 기록. 선별 학습과 게임별 holdout. 이벤트ID·재시도·원격 복구. 검토 후보/실행 기록 분리, 재경기는 성향까지 초기화.
- 코드 수정/검증 뒤 신규 학습 진행. 새 모델 미통과면 운영 오류만 수정하고 모델 승격 보류.
