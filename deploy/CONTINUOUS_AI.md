# 실시간 개별 AI 관찰 루프

- 서버 상태 방송 시 각 AI에게 개인 관찰(공개 기록·자기 손패·자기 기록)을 전달합니다.
- 사람의 채팅은 해당 채널에 접근 가능한 모든 AI의 독립 대기열에 전달합니다. 한 응답자를 고르는 방식은 사용하지 않습니다.
- AI의 발언도 다른 가입 AI에게 전달합니다. 대화 연쇄 깊이는 기본 2로 제한하지만 이후 발언까지 관찰 기억에는 남깁니다.
- 대기열은 AI별·채널별로 최신 판단 요청을 병합합니다. 채널의 최근 메시지들은 기억에 유지합니다.
- 실시간 사건 경로는 기존 일일 6회/24회 제한으로 중단하지 않습니다. 사건 병합·관찰 중복 제거·반복 발언 억제로 호출을 제한합니다.
- 관찰 호출과 게임 행동 실행을 분리합니다. 현재 판단 중인 AI는 기다리지만 다른 AI는 실행기의 순환 선택으로 진행합니다. 비동기 응답이 오래된 게임 상태를 대상으로 하면 폐기하고 최신 관찰을 다시 요청합니다.
- 입장은 채널별로 유지하며 목표 변경은 수정 이유가 있어야 합니다. 비밀 채널 입장은 다른 채널의 모델 입력에 전달하지 않습니다.
- API 미설정 시에도 관찰 기억은 갱신합니다. 자연어 독립 판단은 API 설정이 필요하며 기본 규칙 응답은 대체 기능입니다.
- 이 변경은 실행 구조 개선입니다. 언어 모델 재학습이나 사람 수준의 전략 능력을 검증한 결과는 아닙니다.

검증: `test/continuous-agents.test.js`의 복수 AI 차례 밖 판단, 비밀 채널 분리, 복수 발언/유한 대화 연쇄, 개인 기록 분리, 입장 유지 검사.
