# 대화 AI 업데이트

- 게임별 지속 페르소나4종, 채널별 최근 대화 기억8회, 현재 질문과 게임규칙·현재 단계·공개 결과를 API에 전달합니다.
- API 키가 있으면 AI 자발 고정문구를 중단합니다. 호출 중/쿨다운 때문에 같은 고정문구를 내보내지 않습니다.
- 모델은 수락/거절/역제안을 구분합니다. 검증된 수락 계획은3분/같은 날 동안 보관하고, 실제 해당 단계의 합법 후보가 생겼을 때 선택합니다. 거래 대상 지정은1대1에서만 가능합니다.
- 계획 실행 후 제거합니다. 불가능하거나 만료된 계획은 강제 실행하지 않습니다. 외부 응답은 신뢰할 수 없는 데이터로 보고 역할·수량·후보 권한을 서버에서 검증합니다.
- 익명 메시지 발신ID는 내부에서만 저장하며 클라이언트에는 전달하지 않습니다. 채널 사이 기억은 전달하지 않습니다.
- 이는 BAZE 모델 자체 파인튜닝이나 PPO 대화 재학습이 아닙니다. 페르소나·문맥 설계 및 계획 실행 연결입니다. 실제 학습은 대화/행동 경험과 평가 데이터가 축적된 뒤 별도로 해야 합니다.
- 기존 습득한 게임 정책 가중치는 보존합니다. 외부 대화 요청 한 건으로 행동 계획을 세우며, 거절/역제안은 행동을 강제하지 않습니다. 잘못된 모델 약속이나 개인정보 누설이 완전히 방지된다고 보장하지 않습니다.

## 의도적 블러핑 실험

- `node ai/train-social.js --episodes 1600 --eval-games 480 --seed 9301`: 실제 게임 종료 승패를 보상으로 정직/은폐/허세/보존을 탐색하는 상위 정책 경사 학습. PPO 게임 행동 모델 자체는 바꾸지 않습니다.
- baseline/random/policy/skeptic 네 상대와 3~5인 게임에서 평가합니다. reserve는 원정 거절/0장 지원, bluff는 참가 후 지원 축소 후보를 탐색합니다. 거짓말 횟수에는 보상을 주지 않습니다.
- 시뮬레이터는 자연어 대신 최근 협력 신호를 사용하며, 정책 상대는 신호에 제한적으로 반응합니다. 신호가 실제 발언의 설득 효과나 진실 여부를 검증하지는 않습니다. baseline/random은 일부 편향이 사실상 영향을 주지 않습니다. 덱/역할은 서버 crypto 난수라 동일 seed도 동일 게임 대조군을 보장하지 않습니다.
- 1,600판 학습 후 후보 480판 승률38.125%, 미학습 사회정책 480판40.208%. 승률 향상 확인 실패로 후보 가중치 배포 안 함. `models/social-candidate.json`, `models/social-evaluation.json`은 연구 결과입니다.
- 배포 대화는 수동 설계된 단계별 정직/은폐/허세/보존 전략을 사용합니다. 허세는 상대에게 원하는 믿음을 유도하되 실제 비밀/규칙/공개결과를 노출·조작하지 않도록 지시합니다. 허세 약속은 실행계획으로 강제하지 않습니다. 실제 행동 확률은 검증된 기존 게임정책을 유지하므로 대화 허세와 행동이 정교하게 일치함을 보장하지 않습니다.
- 상대 평가는 공개 중재지원/하급원정 참가 및 본인이 검사한 카드만 이용합니다. 확신은 낮게 유지하고 익명채팅을 특정 인물에 귀속하지 않습니다. 발언 신뢰도나 인간 대상 설득 효과의 학습은 아직 구현되지 않았습니다.
