# 발언·행동 연결 검증

실행 명령:
```sh
node --test test/decision-proof.test.js
node ai/verify-dialogue.js /tmp/opencode/dialogue-proof.json
```

두 번째 명령은 환경에 설정된 실제 API를 호출합니다. 합성 3인 게임에서 시민·반란군 두 AI가 같은 사람 메시지에 독립 응답하고 시민의 지원 약속을 실제 봇 실행기로 실행합니다. 원본 API 키는 출력하거나 결과 파일에 기록하지 않습니다.

실제 BAZE `gpt-6-luna` 검증 결과:
- 시민: “응, 내일 중재에 보탤게. 필요한 힘을 보고 무리 없는 선에서 지원할게.”
- 반란군: “솔직히 내일 중재 지원은 못 해. 다른 방법으로 방어 카드를 마련해보는 게 좋겠어.”
- 후속 대화 이후 다음 날 중재 단계로 이동.
- 실제 보병·장교 카드 소모, 중재력9 증가, 자원만 남음.
- 약속 상태 `fulfilled`, 결정 검증 오류0.

위 문장은 검증 시 모델이 생성한 출력이며 서버 고정 대사가 아닙니다. 실행 결과는 `/tmp/opencode/dialogue-proof-final.json`에 저장했습니다. 요청8회 중7회 완료 후 세션을 닫았으며 마지막 진행 중 호출은 적용하지 않았습니다.

확인된 수정:
- 빠른 대화와 계획 분리의 미배포 변경 제거.
- 목표 문장 표현 변화만으로 응답을 거부하던 검증 완화. 실제 행동 변경 검증은 유지.
- 미래 약속을 새 채팅 계획과 별도로 보존.
- 중재 약속을 원정 제출이나0장 제출로 이행 처리하지 않음.
- 생각 중이라도 기존 실행 가능한 약속부터 실행.

한계: 이 검증은 운영 Render 접속이나 긴 실제 사람 게임이 아닙니다. 말투가 여전히 설명적이고 지원 규모를 충분히 최적화하지 못하는 경우가 관찰됐습니다. 전체 상황에서 사람다운 전략·대화가 완성됐다는 증거로 사용하지 않습니다.
