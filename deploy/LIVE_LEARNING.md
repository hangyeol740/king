# 실제 사람 대화 기반 경험 학습

사람이 AI와 같은 채널에서 대화하면 접근 가능한 AI마다 대화 의도를 기록합니다. AI의 정직·은폐·허세·보존 전략과 실제 실행된 계획을 기록하고, 게임 종료 후 진영 승패 보상으로 문맥별 전략 선호도를 작은 폭으로 갱신합니다.

- 실제 실행된 계획만 학습하며, 변경·폐기된 계획과 무승부에는 승리 보상을 부여하지 않습니다.
- 사람 발언을 정답으로 받아들이거나 직업 주장 자체를 사실로 학습하지 않습니다. 사람의 실제 게임 행동은 단계별 행동 횟수로만 별도 저장하며, 현재 PPO 행동 보상·가중치에는 사용하지 않습니다. 향후 후보 평가에서 사람이 자주 선택한 행동과의 차이를 진단하는 용도입니다.
- 공유 학습 데이터에는 원문·닉네임·방 코드가 아니라 진영/단계/의도별 전략 가중치와 횟수만 저장합니다. 기존 게임별 대화 기억은 개인 상태에 별도로 유지됩니다.
- `.data/ai-learning.json`에 저장하고 기존 Supabase 영구 스냅샷이 설정돼 있으면 `learning` 필드에도 함께 저장합니다. 재시작 시 복구합니다.
- 다음 판단의 전략 선택에 학습값을 사용합니다. 이미 유지 중인 입장은 학습값 때문에 임의로 바꾸지 않습니다.
- `/api/ai-chat/status`의 `learning`에서 학습된 게임 수·판단 수·문맥 수를 확인할 수 있습니다.
- 이것은 소규모 온라인 전략 선택 학습이며 LLM 가중치 미세조정이나 대화 원문 PPO 학습이 아닙니다. 승률 개선은 별도 평가가 필요합니다.

## 응답 속도

게임 명령은 메모리 상태 적용 후 즉시 방송·응답하며 저장은 기존 순차 저장 큐에서 처리합니다. 따라서 저장 실패 또는 저장 완료 전 프로세스 종료 시 최근 상태 손실 가능성이 있습니다. 제작 클릭은 클라이언트에서 순서대로 전송하며 중복 재시도는 하지 않습니다. 새 채팅 렌더 시 항상 가장 아래로 이동합니다.
