# 업로드 상태

이 커밋은 AI 재설계와 현재 게임/웹 변경 사항을 보관하는 미완성 작업 커밋이다.

- AI 전체 명세 구현·전략 품질 합격 및 새 모델 승격은 완료되지 않았다.
- 업로드 직전 전체 테스트를 실행했으며 여러 검사가 실패했다. 주요 원인은 현재 저녁 결투 단계와 기존 낮 전투 후보/테스트의 불일치, 변경된 반란 목표·기권·투표 규칙과 기존 테스트의 불일치, 브라우저 테스트 DOM 모형과 화면 코드의 불일치다.
- 이전 시점의 전체 테스트 통과 기록을 이 커밋의 통과 근거로 사용하지 않는다.
- 실행에 연결된 웹 리소스와 Google 로그인 모듈을 포함한다. Google 로그인은 GOOGLE_CLIENT_ID 설정이 필요하다.
- 원본 에셋 압축파일·개인 작업 자료·실험 모델·기존 삭제 작업은 업로드 범위에서 제외했다.
- GitHub 업로드는 Render 운영 성공 또는 배포 검증을 뜻하지 않는다.
